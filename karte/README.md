# カルテ自動作成（Googleスプレッドシート）

カウンセリングフォームが送信されると、スプレッドシートにお客様ごとのカルテシートが1枚自動でできます。

## カルテの形

| 項目 | お客様の回答 | ┃ | 深掘りの質問 | ヒアリングメモ |
|---|---|---|---|---|
| お悩み | 巻き肩、猫背 | ┃ | ・どんな時に気になりますか？<br>・なんで気になりますか？<br>・… | （スタッフが記入） |
| お悩み | 腰痛 | ┃ | ・どんな時に気になりますか？<br>・反ると痛いですか？丸めると痛いですか？<br>・… | |

- お悩みのチェック項目は1つずつ行に分かれ、右側に聞くことの例とメモ欄が付きます。
- 目標・大切な予定・これまでの対策なども、右側に深掘りの質問が付きます。
- 下に「まとめ」（Claudeが作る初回メニュー案など）と「初回の当日記入」欄があります。
- ほかに「お客様一覧」「セッション記録」「種目一覧」シートがあります。

質問の文言は `karte.gs` の `BASE_CONCERN_QUESTIONS`、`EXTRA_CONCERN_QUESTIONS`、`ITEM_QUESTIONS` で変えられます。

## 設定のしかた（最初に1回）

フォームの **編集権限を持っている人** のGoogleアカウントで行ってください。

1. カルテ用のスプレッドシートを開く。
2. メニュー「拡張機能」→「Apps Script」を開く。
3. 最初からある `コード.gs` の中身を全部消して、`karte.gs` の中身を貼り付けて保存する。
4. `CONFIG.FORM_ID` が使っているカウンセリングフォームのIDになっているか確認する。フォーム編集画面のURL `docs.google.com/forms/d/〇〇〇/edit` の〇〇〇の部分です（お客様に送る `/forms/d/e/…/viewform` のIDとは違います）。
5. スプレッドシートを再読み込みすると、メニューに「カルテ」が出る。「カルテ」→「初期設定（最初に1回）」を押し、出てくる権限の確認を許可する。
6. まとめ欄もClaudeに書かせる場合は、「カルテ」→「Claude APIキーを登録」でキーを登録する（[Claude Console](https://platform.claude.com/) で発行）。

これでフォームが送信されるたびにカルテができます。すでに届いている回答からは「カルテ」→「お名前で回答を探してカルテを作る」で作れます。

## 注意

- APIキーを登録すると、回答の内容（名前・住所を含む）がまとめ作成のためにAnthropicのAPIに送られます。気になる場合はキーを登録せずに使ってください（まとめ欄が空欄になるだけです）。
- まとめの料金は、1人あたり10円前後の想定です。
- スプレッドシートの共有はスタッフのみにしてください。
